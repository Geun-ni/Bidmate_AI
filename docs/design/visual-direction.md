| Instrumentl | — | — | — | 보안 확인 페이지로 차단되어 측정하지 못함 |

**발견**
1. 국내 입찰·조달 사이트는 **전부 파란색 + 흰 바탕**이다. 파랑만 쓰면 신뢰는 얻지만 구분이 안 된다.
2. 눈에 남는 해외 서비스는 **중립색 바탕 + 개성 있는 포인트 하나**(보라, 핑크, 검정)와 **제목 글꼴의 개성**, **도메인을 상징하는 그래픽 하나**(Sweetspot의 지도)로 차별화한다.
3. 국내 사이트의 공통 불만(팝업 중첩, 광고, 정보 과밀)은 그대로 우리의 차별점이 된다: **조용하고 정돈된 업무 화면**.

## 3. 컨셉 후보

### A. 설계도면 (Blueprint) — 추천
전기공사 업체가 매일 보는 **단선결선도·시공 도면**의 언어로 만든 업무 도구.

- **바탕:** 제도용지 같은 따뜻한 회백 `#F6F7F4`, 헤더·빈 화면에만 옅은 모눈 격자.
- **주색:** 잉크 네이비 `#14234B` (SRM 네이비와 어울리되 다른 값), 도면 블루 `#2B5BD7` (링크·선택·주 버튼).
- **포인트:** 신호 주황 `#E8590C` — **마감 임박에만** 쓴다. 공사 현장 안전색이라 업종과 맞고, 국내 사이트의 파랑 일색과 구분된다.
- **판정색:** 충족 `#1E7F5C`, 확인 필요 `#9A6B00`(황토), 불일치 `#C23B32`, 종료 `#6B7280`. 마감 주황과 헷갈리지 않게 확인 필요는 **연한 배경 + 아이콘**, 마감은 **꽉 찬 칩**으로 모양을 다르게 한다.
- **글꼴:** 본문 Pretendard, 공고번호·코드·금액은 고정폭 숫자(예: JetBrains Mono)로 "도면 표기" 느낌.
- **시그니처:** 진행 단계와 서류 진행률을 **결선도(점과 선)** 로 그린다. 로고도 회로 선이 체크 표시로 끝나는 마크.
- **모션:** 선이 그려지는 동작(도면을 펜으로 긋는 느낌) 위주. 반짝임·네온·무한 반복은 쓰지 않는다.
- **다크모드:** 청사진(blueprint) 그 자체 — 짙은 남색 바탕에 하늘색 선.

### B. 브리핑 문서 (Editorial)
잘 쓰인 **검토 보고서**처럼 읽히는 화면. Tendium 계열.

- 먹색·회백 단색 위주 + 깊은 청록 `#0F6E62` 하나만 포인트.
- 제목은 세리프(예: 마루부리), 본문은 Pretendard.
- 원문 근거를 **각주 번호**로 표시하고 누르면 인용문이 열린다. 형광펜이 그어지는 모션.
- 장점: 근거 인용이라는 서비스 원칙과 가장 잘 맞고 고급스럽다. 단점: 마감·점수 같은 "계기판" 정보의 긴장감이 약하다.

### C. 관제실 (Control room)
전력 **관제 시스템(SCADA)** 처럼 어두운 화면에 상태 표시등.

- 다크 우선 슬레이트 + 볼트 옐로 포인트, 고밀도 표.
- 장점: 강렬하고 발표 화면에서 돋보인다. 단점: 낮 시간 사무 업무에 어두운 기본 화면은 피로하다는 지적이 있고, 소규모 업체 사용자에게 위압적일 수 있다.

## 4. 추천안(A) 적용 범위

| 화면 | 바뀌는 점 |
| --- | --- |
| 공통 | 색·글꼴 토큰 교체, 헤더 모눈 패턴, 모서리 반경 12px → 6px (단단한 업무 도구 느낌) |
| 대시보드 | 공고 카드 왼쪽에 판정색 "배선" 띠, 마감 임박 카드만 주황 칩, 요약 숫자 카운트업 |
| 관심공고 달력 | 일정 점을 결선도 기호(○ 신청마감, ● 투찰마감, ◇ 개찰)로 |
| 공고 상세 | 진행 단계를 결선도로, 지나온 구간 선이 그려지며 등장 |
| 점수 계산 | 반원 계기판 게이지 + 95점 기준 눈금, 바늘이 점수까지 이동 |
| 필요서류 | 진행률을 배선 선으로, 체크 표시가 그려지는 동작 |
| 빈 상태 | 플러그가 빠진 도면 선화 |

**모션 원칙:** 0.2~0.7초, 한 번만 재생. 계속 반복되는 효과 없음. OS "동작 줄이기" 설정 시 전부 끔.

## 참고

- 한전 CI의 공식 색상값은 공개 자료에서 확인하지 못했다. 한전 로고·색을 그대로 쓰지 않고, 어울리는 계열만 참고한다.
- 벤치마크 값은 각 사이트 홈 화면에서 브라우저가 계산한 스타일을 면적·빈도 순으로 추출한 것이다. 브랜드 공식 값과 다를 수 있다.
