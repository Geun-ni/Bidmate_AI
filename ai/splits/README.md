# 제출서류 추출용 공고 분할

`notices_20261121.csv`는 `bid_attachment.csv`, `bid_document_content.csv`,
`bid_notice.csv`의 현재 스냅샷에 대한 고정 분할이다. `notices_20261121.json`에는
입력 파일의 SHA-256과 유형·가격대 분포를 기록했다.

| split | 공고 수 | 용도 |
| --- | ---: | --- |
| development | 114 | 원문 검토, 정답 작성, 규칙 개발 |
| validation | 24 | 개발 중간 점검과 오류 분석 |
| test | 25 | 규칙을 확정한 뒤 최종 평가 |

같거나 매우 비슷한 적격심사기준의 긴 문장 집합을 가진 공고는 한 `template_group`으로
묶었다. 그룹은 분할을 가로지르지 않는다. 분할 전에 원문을 살펴본 10건과 10건 이상인
큰 템플릿 묶음은 개발 집합에 고정했다. 제목에서 읽은 공고 유형과 `presumed_price`
(VAT 제외 추정가격)를 이용해 나머지 그룹을 배분했다. 고정 난수 시드는 20261123이다.

이 데이터에는 같은 템플릿을 공유하는 송전공사 31건이 있다. 템플릿 누출을 막기 위해
31건 전체가 개발 집합에 있다. **최종 테스트에는 송전공사가 없으므로 송전공사 성능을
테스트 점수로 주장할 수 없다.** 드문 유형도 유형별 표본 수를 함께 확인해야 한다.

분할은 정답 목록이나 추출 성공률을 뜻하지 않는다. 개발·검증용 원문은 규칙을 개선하는 데
사용할 수 있다. 테스트 25건은 [첫 평가](FINAL_TEST_REPORT.md)에 사용했다. 이 평가를
보고 규칙을 수정하면 같은 25건은 다음 버전의 독립 최종 테스트가 아니다. 서류 단위
점수를 내려면 완전한 정답 목록을 독립적으로 검수한 뒤 누락·오탐·조건 오류를 비교해야 한다.

재현 명령:

```powershell
python -m ai.split_notices 실제데이터/bidmate_csv_20261121 --output .local/split-check.csv
```

기존 분할 파일은 기본적으로 덮어쓰지 않는다. 입력 CSV를 바꿔 새 실험을 하는 경우
별도 출력 경로를 사용한다.
