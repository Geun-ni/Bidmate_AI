# 고정 최종 테스트 25건: 현재 규칙 평가

입력: `bid_document_content.csv`와 고정 분할 `ai/splits/notices_20261121.csv`.
API 호출 없음. 규칙을 고치지 않고 최종 테스트 집합을 실행했다.

## 결과

**공고 단위 운영 준비 판정: 성공 0/25건(0%), 실패 25/25건(100%).** 성공은
서류를 개별 항목으로 분리하고 제출 조건·단계·근거를 확인해 추천 화면에 표시할 수 있는
상태로 정의했다. 현재 25건 모두 문장 단위 후보만 있고 검수 상태가 `REVIEW`이므로
이 기준을 충족하지 못한다. 이 수치는 서류 단위 추출 정확도가 아니다.

- 25/25 공고에서 공고문과 적격심사기준 본문을 읽을 수 있었다. 성공 본문 52개,
  실패한 원래 첨부 1개는 같은 공고의 대체 공고문 본문이 있다.
- 기존 정규식 서류 후보 520행은 전부 `REVIEW`, 공고 상태는 전부 `PENDING`이다.
  검수된 최종 제출서류 목록은 0/25건이다.
- 별도 근거 탐색기가 명시적 제출 문장 299줄과 뒤따르는 번호 목록 104줄을 찾았다.
- 번호 목록 104줄을 원문으로 대조해 제출 목록 조항 85줄과 무관한 소제목·평가표 19줄로 분류했다.
- 기존 정규식 결과가 동일한 제출 목록 원문 줄을 보존한 것은 **22/85 (25.9%)**이다.

이 수치는 **정확한 제출서류 추출률이 아니다.** 같은 서류를 다른 줄에서 후보로 잡았을
수도 있고, 하나의 줄에 여러 서류가 있을 수 있다. 조건·제출 시점·대체 관계도 이 지표에는 없다.

## 규칙 v2 사후 재평가

이 절은 앞의 25건 오류를 본 후 작성한 `ai/rule_documents.py`를 **같은 25건에 다시 실행한**
결과다. 개발에 사용한 사례이므로 독립 최종 테스트 점수로 해석하지 않는다.
기존 SQLite 후보와 비교하기 위해 결과는 별도 `rule_v2_test_items.jsonl`에 저장했고,
전부 `REVIEW` 상태다. API 호출은 없었다.

| 확인 항목 | 기존 규칙 | 새 규칙 |
| --- | ---: | ---: |
| 앞서 선별한 서류명 사례 34개 중 후보 이름에 나타난 사례 | 2/34 | 34/34 |
| 번호형 목록의 구체적 제출 조항 75줄 중 동일 원문 줄에 연결된 사례 | 22/75 | 75/75 |
| “기타 별도 제출 요청서류”처럼 현재 이름을 알 수 없는 조항 | 0/10 | 0/10, 미확정으로 남김 |

새 규칙은 25건에서 131개 후보를 생성했고, 131개 인용문 모두 해당 원문에 실제로
존재한다. **서류 단위 정확도 또는 25건의 완전 추출 성공률은 아직 계산할 수 없다.**
후보에는 여러 서류가 합쳐진 이름과 적용 조건을 확정할 수 없는 항목이 남아 있다.
기존 DB의 검수 결과를 덮어쓰지 않았으며, 운영 DB 삽입도 하지 않았다.

같은 규칙을 개발 집합 114건에 실행했을 때는 462개 후보를 만들었고 **17건은 후보가
0개**였다. 대부분 소규모 감리용역 또는 PQ 공고로, 제출서류가 공고문에 나열되거나
적격심사기준의 부록·평가방법에 흩어져 있어 현재의 적격심사기준 명시 목록 규칙에
걸리지 않았다. 따라서 25건의 이름 포착 결과를 전체 163건의 성능으로 확대할 수 없다.
해당 공고번호는 E012607031, E012607140, E012608140, E012608150, E012608152,
E012608155, E012608156, E012608160, E012608166, E012608177, E012608178,
E012608181, E012608217, E012608225, E012608233, E012608234, E012608235다.

검증 집합 24건에도 동일한 룰을 실행하면 97개 후보가 생성되고 8건은 후보가 0개다.
전체 163건 기준으로는 **138건에서 후보 690개가 나왔고, 25건은 후보가 0개**다.
이는 하나 이상의 후보가 있는 공고 수이며 전체 제출서류를 정확히 추출한 성공 건수가
아니다. 후보 0개인 25건 모두 공고문과 적격심사기준의 읽을 수 있는 본문은 있다.
LLM API는 아직 이 25건에 실행하지 않았으므로 LLM 추출 성공 건수는 측정되지 않았다.
